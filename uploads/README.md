# uploads/

Drop files here (on GitHub: **Add file → Upload files**) and they appear on the site
after the next sync (a few minutes).

- `uploads/cosmos/` → tagged **Cosmos** (save images from Cosmos here)
- `uploads/pinterest/`, `uploads/arena/` → tagged with that app
- anything else → tagged **Uploads**

Add a folder named `images`, `links` or `sources` anywhere in the path to force
the category, e.g. `uploads/sources/reading-list.pdf`. Otherwise images go to
Images and PDFs / text files go to Sources.
